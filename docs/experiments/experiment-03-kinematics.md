# Experiment 03 — Robot modelling and kinematics

## Objective

The original laboratory exercise explored Denavit–Hartenberg (DH) modelling and serial-link robot construction in MATLAB.

## Topics covered

- standard DH parameters;
- modified DH parameters;
- revolute and prismatic joints;
- base and tool transforms;
- interactive robot visualization;
- manual reconstruction of textbook serial-link examples;
- PUMA 560 modelling as preparation for forward/inverse kinematics work.

## Public-project connection

The final portfolio project does not reproduce every classroom DH model. Instead, it focuses on the PUMA 560 model supplied by Peter Corke's Robotics Toolbox and uses it as the target for the trajectory-planning pipeline.

This keeps the public repository focused while preserving the conceptual progression from link parameters and robot models to Cartesian poses and inverse kinematics.
