# Changelog

## 1.0.0 — Portfolio refactor

- Reorganized robotics coursework into a focused MATLAB repository.
- Added explicit Z-Y-X and Z-Y-Z rotation conversion utilities.
- Corrected ambiguous axis naming and inconsistent Euler-angle conventions.
- Added proper rotation-matrix validation and singularity reporting.
- Added reusable E/C path generators and `mstraj` interpolation wrapper.
- Added PUMA 560 inverse-kinematics simulation wrapper.
- Added runnable examples and toolbox-independent tests.
- Added English and Simplified Chinese documentation.
- Added curated historical simulation images from the author's own report.
- Excluded third-party teaching material and Git-ignored personal original reports.
